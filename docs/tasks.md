# AgroBits — Tareas

Estado: pendiente de planificación.

Las tareas definitivas se generarán a partir de `docs/plan.md` una vez aprobado.

Cada tarea deberá incluir:
- Identificador.
- Objetivo.
- Dependencias.
- Archivos afectados.
- Criterios de aceptación.
- Pruebas requeridas.
- Riesgos relevantes.

Reglas:
- No incluir tareas de implementación hasta aprobar el plan.
- Toda tarea derivada de `docs/spec.md` debe trazarse a un requisito (R-01…R-14) y a sus criterios de aceptación.
- Las tareas que dependan de criterios marcados `[F2]` en la especificación no pueden cerrarse en la Fase 1.
